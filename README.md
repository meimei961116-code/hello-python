# Hello Python 👋

A simple, elegant Python greeting script demonstrating iterative version control with Git and GitHub.

---

## 📌 Features

- **Antigravity AI Intro**: Displays an introduction from Antigravity, an agentic AI coding assistant from Google DeepMind.
- **Dynamic Date**: Automatically inspects and prints today's execution date.
- **Minimalist & Clean**: Zero external dependencies, pure Python standard library.

---

## 🚀 Quick Start

### Prerequisites

- Python 3.10 or later

### Running the Script

```bash
python hello.py
```

**Example Output:**
```text
Hello! I am Antigravity, an agentic AI coding assistant from Google DeepMind.
Today is 2026-10-12, ready to pair program with you!
```
